# Portfolio pessoal

Site estatico simples para hospedar gratuitamente na Vercel, com um botao de
download para o resume.

## Como personalizar

1. Edite `index.html` e troque `Seu Nome`, cargo, textos, email, LinkedIn e GitHub.
2. Coloque seu arquivo de curriculo na raiz do projeto com o nome `resume.pdf`.
3. Abra `index.html` no navegador para conferir localmente.

## Deploy na Vercel

1. Suba este projeto para um repositorio no GitHub.
2. Na Vercel, clique em `Add New...` > `Project`.
3. Importe o repositorio.
4. Como e um site estatico, a Vercel deve detectar sem precisar de build.
5. Clique em `Deploy`.
